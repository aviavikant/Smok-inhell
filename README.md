# Smok'in Hell Website

A responsive static website built from the 22 supplied/created visuals.

## Structure
- `index.html` — complete one-page website
- `assets/css/styles.css` — styling and responsive layout
- `assets/js/app.js` — gallery filters, mobile navigation and image lightbox
- `assets/images/brand/hero-black-hookah.jpg` — hero image
- `assets/images/brand/services-contact-card.jpg` — original services/contact artwork
- `assets/images/gallery/` — 20 renamed product showcase images

## Run locally
Open `index.html` directly in a browser, or run a simple local server from the folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing
Review phone numbers, social links, service wording, availability, and any legal/age requirements relevant to your operations.
